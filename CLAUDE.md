# mcp-sql-analyst

Read-only MCP server for SQLite, written in TypeScript. Small enough to read in one sitting.

## Stack
- Node 24.10+, strict TypeScript, `@modelcontextprotocol/sdk`, stdio transport
- `node:sqlite` (no native build step), Vitest, Biome

## Commands
- `npm test` builds, then runs the tests
- `npm run lint` checks formatting, lint rules, and test types

## Architecture
`index` > `server` > `db-client` > (one process per call) > `db-process` > `db`.
Only `db.ts` touches SQLite. `limits.ts` and `db-protocol.ts` import nothing.

## Design rules
- Safety has two layers: the read-only connection and the SQLite authorizer, both set in `openReadOnly`. Never replace them with parsing or regex.
- Every tool goes through `openReadOnly`, and every result row goes through `runQuery`.
- All limits live in `limits.ts`.
- Run every database operation in a disposable process killed on timeout. `worker.terminate()` cannot stop a blocked `node:sqlite` call.
- Never write to stdout from the server: it carries the MCP protocol.
- Throw errors and let McpServer turn them into tool errors, without stack traces or file paths.
- The sample database is synthetic and generated by a script.
- Do not add other databases, HTTP transport, or auth.

## Done means
`npm run lint` and `npm test` pass, and `verify-server` succeeds. A new safety control needs a test that fails when the control is removed.
